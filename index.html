kan-linux - Pure, Source-built, Agent-first Linux

kan-linux is a pure, source-built, agent-first Linux distribution for building customizable Wayland desktops.

  • Monorepo containing all patched component source code
  • Full source-based: from gcc, musl/glibc, busybox, system utils, mesa to Wayland desktop stack
  • Every component ships with verified custom patches
  • Self-contained source snapshots, can build a live ISO directly from source code

The kan-linux way

  • Minimal

    We like simplicity and aim to keep the distribution as small and as simple as possible.

  • Open Core

    The distribution and related components are freely available under the MIT license. The development process is open and everyone is welcome to join.

  • Explore and have fun!

    We build kan-linux in the spirit of play. Contributors are encouraged to try crazy ideas, build wild demos, and push the edge of what’s possible.
