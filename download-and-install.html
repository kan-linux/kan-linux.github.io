Download & integrity verification

Download the LiveISO and its SHA256 checksum from the GitHub release page. The commands below use v0.3.4 as an example. 

wget https://github.com/kan-linux/kan/releases/download/v0.3.4/kan-linux-0.3.4-x86_64.iso
wget https://github.com/kan-linux/kan/releases/download/v0.3.4/kan-linux-0.3.4-x86_64.iso.sha256

Verify the downloaded image with the SHA256 checksum:

sha256sum -c kan-linux-0.3.4-x86_64.iso.sha256

If the output shows OK, the file is intact:

$ sha256sum -c kan-linux-0.3.4-x86_64.iso.sha256
kan-linux-0.3.4-x86_64.iso: OK

Run the LiveISO in a virtual machine

You can try the LiveISO on any Linux host with QEMU installed.

Launch the LiveISO

qemu-system-x86_64 -enable-kvm -cpu host -m 4G -smp 2 \
  -cdrom kan-linux-0.3.4-x86_64.iso \
  -device virtio-vga,xres=1920,yres=1080 -display gtk \
  -smbios type=1,manufacturer="kan-linux",product="kan-linux 0.3.4",version="0.3.4" \
  -usb -device usb-tablet \
  -audiodev pa,id=audio0,out.buffer-length=100000,in.buffer-length=100000,timer-period=1000 \
  -device intel-hda -device hda-duplex,audiodev=audio0 \
  -netdev user,id=net0,hostfwd=tcp::2222-:22 \
  -device virtio-net-pci,netdev=net0

Install Kan-Linux to a virtual disk

1. Create a virtual disk

qemu-img create -f qcow2 kanlinux.qcow2 20G

2. Launch the LiveISO with the virtual disk attached

qemu-system-x86_64 -enable-kvm -cpu host -m 4G -smp 2 \
  -drive file=kanlinux.qcow2,format=qcow2,if=virtio \
  -cdrom kan-linux-0.3.4-x86_64.iso -boot d \
  -device virtio-vga-gl,xres=1920,yres=1080 -display gtk,gl=on \
  -smbios type=1,manufacturer=Kan-Linux,product=Kan-Linux 0.3.4,version=0.3.4 \
  -usb -device usb-tablet \
  -audiodev pa,id=audio0,out.buffer-length=100000,in.buffer-length=100000,timer-period=1000 \
  -device intel-hda -device hda-duplex,audiodev=audio0 \
  -netdev user,id=net0,hostfwd=tcp::2222-:22 \
  -device virtio-net-pci,netdev=net0

3. Run the installer from the LiveISO

The installer supports single-OS installation to a specified partition or a standalone disk among multiple disks. Launch it from the live session and follow the prompts.

Installation behaves the same in virtual machines and on physical x86-64 laptops and PCs.

4. Boot the installed system

Launch again without -cdrom / -boot d, or simply keep the same command — the virtual disk now holds Kan-Linux:

qemu-system-x86_64 -enable-kvm -cpu host -m 4G -smp 2 \
  -drive file=kanlinux.qcow2,format=qcow2,if=virtio \
  -device virtio-vga-gl,xres=1920,yres=1080 -display gtk,gl=on \
  -smbios type=1,manufacturer=Kan-Linux,product=Kan-Linux 0.3.4,version=0.3.4 \
  -usb -device usb-tablet \
  -audiodev pa,id=audio0,out.buffer-length=100000,in.buffer-length=100000,timer-period=1000 \
  -device intel-hda -device hda-duplex,audiodev=audio0 \
  -netdev user,id=net0,hostfwd=tcp::2222-:22 \
  -device virtio-net-pci,netdev=net0

Use the LiveISO on real x86-64 laptops and PCs

Requirements. Kan-Linux should run on any x86-64 compatible machine with a minimum of 2 GiB RAM(tested and verified in QEMU VM), though more memory (4+ GiB RAM is recommended) is better.

Disk space. Minimum 10 GiB — more is better.

1. Create a LiveUSB

Attention. Double-check the USB device path with lsblk before writing — writing to the wrong device will destroy your data.

# verify the USB device path is /dev/sdb with lsblk  (ATTENTION here)
lsblk

sudo dd if=kan-linux-0.3.4-x86_64.iso of=/dev/sdb bs=4M status=progress conv=fsync

2. Configure BIOS settings

Adjust your laptop or PC BIOS before installing Kan-Linux from the LiveUSB. The exact option names vary by firmware vendor.

Essential

Two changes are required — note that the first one is a disable:

  1. Disable Secure Boot. Open the Secure Boot section (usually under a Security tab) and make sure Secure Boot Enable is unchecked / disabled. The LiveUSB will not boot while Secure Boot is enabled.
  2. Put the LiveUSB first in the boot order. In Boot Sequence / Boot Order, move the entry for your USB stick (shown as UEFI: <your USB>) to the top of the list, and keep the boot mode set to UEFI.

Optional

If your BIOS has a SATA Operation option (common on Dell firmware), set it to AHCI instead of RAID On. Skip this if the option does not exist.

3. Install from the LiveUSB

Boot from the LiveUSB, then launch the installer. The process is the same as in a virtual machine (see the screenshots above).

4. First boot on real hardware

Update an installed system

To upgrade from an already installed Kan-Linux, boot the LiveUSB (created from the LiveISO of the new release) and run the installer as usual. When the installer asks for the installation mode, choose Overwrite Installation — this installs the new release over the existing system, and the data in your /home directory is preserved.
