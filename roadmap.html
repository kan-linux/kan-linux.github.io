Roadmap

From PoC in QEMU to full self-hosting on real x86-64 machines, and on to the Agent-First stage — where Kan-Linux is heading.

  • Stage 1 — PoC validation (2019.5.28-2026.10.5 · 2019 May 28 Initial project, 2026 Sep Re-launch project) Complete PoC validation of Kan-Linux via QEMU virtual machine.
  • Stage 2.1 — Desktop shell Integrate a preliminary, feature-limited, customized Omarchy desktop shell and login greeter for QEMU virtual machine environments.
  • Stage 2.2 — Installer Enable and validate Kan-Linux installer via QEMU virtual machine.
  • Stage 2.3 — Stabilize (VM) Refine and stabilize via QEMU virtual machine.
  • Stage 2.4 — Real hardware Enable and validate the Kan-Linux boot and runtime support for physical x86_64 desktop PCs / laptops.
  • Stage 2.5 — Desktop-native AI Agent Integrate desktop-native AI Agent in Kan-Linux on physical x86_64 hardware.
  • Milestone — Full self-hosting Kan-Linux achieved full self-hosting for the first time at 15:20 (UTC+0800) on Nov 09, 2026. All subsequent development, building and iteration of Kan-Linux will happen inside Kan-Linux itself.
  • Stage 2.6 — Refine & stabilize Refine and stabilize for physical x86_64 desktops / laptops.
  • Stage 3 — Agent-First
  • Stage 3.1 — HLD (high level design)
  • Stage 3.2 — llama.cpp + Agent-based build system for other components
  • Stage 3.3 — PoC
