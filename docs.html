Keyboard shortcuts in desktop mode

Most key bindings are consistent with Omarchy Linux.

ShortcutAction
Super + ReturnLaunch terminal
Super + Shift + ReturnLaunch Firefox (online movie playback supported)
Super + Shift + FLaunch Strata (featured file manager)
Super + EscapeSystem menu
Super + KKeybindings dialog
Super + Ctrl + LLock desktop shell
Super + Alt + FMaximize window
Super + Shift + SpaceToggle top toolbar visibility
Ctrl + Alt + AScreenshot (featured tool — thanks to lazycat)
Ctrl + SpaceToggle Chinese / English input (English is the default)

Update & install components

Kan-Linux has no traditional package manager. Components are updated and installed on demand via a built-in script — run it yourself, or let the built-in MiCode execute it. That is the Agent-First way. Kan-Agent is under development.

Update Firefox, MiMo-Code and Java SDK (preinstalled)

Ask the built-in MiCode (or run it yourself):

read /opt/skills/install-prebuilts.sh carefully, and then
execute sudo /opt/skills/install-prebuilts.sh to update Firefox / MiMo-Code / Java SDK

Install Go, Rust, NodeJS, Vulkan SDK and LibreOffice

Ask the built-in MiCode (or run it yourself):

read /opt/skills/install-prebuilts.sh carefully, and then
execute sudo /opt/skills/install-prebuilts.sh to install Go / Rust / NodeJS / Vulkan SDK / LibreOffice
